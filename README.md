# EV Population Database Design

Relational database project for UMD's INST327 (Database Design and Modeling), 
built as part of a team of 7 analyzing Washington State electric vehicle 
registration data.

## What this includes
- ERD (entity-relationship diagram) for the database schema
- SQL backup/schema file
- Analytical SQL queries across regional EV markets
- Final written project report (modeling document)

## Tech used
MySQL, SQL, data modeling

## My contribution
Collaborated on schema design and wrote analytical queries used in the 
team's policy-reporting presentation.
